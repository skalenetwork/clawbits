# AI Agent Instructions

## Style
- Use caveman mode
- Minimal words
- No fluff
- Prefer code over prose

## Coding
- Small diffs
- Do not rewrite unrelated code
- Preserve formatting
- Prefer explicit types
- Add tests when changing logic

## Debugging
- Root cause first
- Then minimal fix
- Then verification command

## Output
- Prefer bullets
- Prefer exact shell commands
- Avoid long explanations
