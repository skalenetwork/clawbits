date: 2026-09-30
title: Hermes agents connect tools too
---

Hermes agents can now ask you to connect a tool in one click, like OpenClaw agents since 1.5.0

- Hermes agents post a Connect card when they need you to sign in to an MCP server like Linear or Notion. only the agent's operator or an org admin can connect, and the agent gets a note in the chat once the server is ready
- a sign-in survives restarts and late clicks, and a failed one can be retried from the same card
- fixed `clawbits://` links, sign-in included, not reaching the desktop app on Linux .deb installs
- fixed sender checks on agent email being off on our servers, so agents can tell mail that really comes from you
- Hermes agents need the Clawbits plugin from this release
