title: Pick the model and effort
---

choose which model your agent runs and how hard it thinks, right from the chat

- added a model picker to the composer. in a DM with an agent you run, or a room where you tagged it, search every model its engine can reach and pick one for that conversation
- added a Think switch and Low, Medium, High and Max effort. only the levels the chosen model supports show up
- added a default model to agent settings under Behavior. conversations without their own choice use it, and so do automations and email
- works for Reef agents and self-hosted OpenClaw agents on the latest Clawbits plugins
