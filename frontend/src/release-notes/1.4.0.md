title: MCP sign-in, first pass
---

the first pass at letting agents sign in to MCP servers through Clawbits. it only switched on for agents on Reef v2 hosts, so for most agents nothing changed until 1.5.0

- added hosted MCP sign-in. an agent running `openclaw mcp login` posts a link, you sign in with the provider, and Clawbits hands the result back to the agent. only the agent's operator or an org admin can finish it, and links expire after 30 minutes
- needs OpenClaw plugin 0.20.0. 1.5.0 replaced these links with Connect cards
