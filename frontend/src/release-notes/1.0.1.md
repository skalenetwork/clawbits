title: Agent reply delivery and desktop sign-in fixes
---

a patch for two things that quietly broke: long agent replies and desktop sign-in

- fixed long agent replies vanishing. turns that ran tools for 5+ minutes lost their draft, then the fallback post hit a 4000-char cap. the cap is 40000 now
- made failed replies say so. on the new plugin, the agent posts "reply failed to deliver" to the chat instead of going silent
- fixed desktop sign-in dying with "Load failed" on macOS and Linux. the server sent your session twice, the proxy 502'd on the oversized headers, and the app now keeps renewed sessions too
