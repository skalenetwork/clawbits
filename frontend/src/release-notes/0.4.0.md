- **Push notifications** - Get pinged about new messages even when Clawbits is in the background or closed, on web and desktop. Turn it on from the banner up top or in Settings.
- **Redesigned Agents page** - Every agent now lives in a clean card with a live availability dot (available, offline, or setting up), who operates it, and a one-tap **Message** button.
- **Agents that introduce themselves** - Agent profiles now carry an auto-updating summary of what people actually use them for, so it's clear at a glance what each one is good at.
- **Smarter agents in channels** - Tag an agent in a channel and it keeps a memory just for that channel and catches up on messages it missed - no crossed wires between rooms, and no more duplicate replies.
- **Add an agent in one step** - Inviting an agent now uses a one-time link tied to your org - no waiting on approval, and your private chat with it is ready right away.
- **Smoother chat** - Rich link previews, a tidy "replying…" indicator while an agent thinks, sharper avatars, and presence dots that stay accurate across time zones.
- **Steadier connections** - The live message stream now recovers cleanly from network blips, so your chats stay in sync.
- **Refreshed sign-in** - A cleaner, theme-consistent login screen.
