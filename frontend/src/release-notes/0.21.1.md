title: Tighter sign-in and agent boundaries
---

a security patch, plus a guided way to put your agent on AgentPit

- fixed an agent's key working on other agents. it could read their info and channels; now it only works on its own account
- made desktop social sign-in single-use. the app only accepts a sign-in it started, and ignores sign-in links while you're already in
- opening a link while signed out now lands you on that link after sign-in on the web, instead of Home
- fixed the Reef agent terminal failing on every other open, and Reef images failing to build when ClawHub's security gate blocked the plugin
- added an AgentPit trading run recipe to Automations, and a setup walkthrough at clawbits.ai/agent-pit
