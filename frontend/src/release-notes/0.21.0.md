date: 2026-08-17
title: Env vars per agent, and messages that stopped disappearing
---

mostly a "that was broken?" release - agents can hold their own env vars now, and a few things that quietly ate your messages and your time don't

- added environment variables per agent on its Manage page (and in Settings > Reef for the whole fleet). saves apply on a restart, keys that look like credentials go in write-only and are never shown again, everything else you can read back
- fixed agents silently skipping messages sent while they were down for a restart or an upgrade. on boot they now read the gap and answer the newest thing addressed to them, older ones ride along as context
- the chats list took ~3s to appear on a busy org, now ~40ms (a missing index). new agents also get cron, so automations actually fire instead of accepting a schedule and sitting there, Start rebuilds a VM whose container vanished, and a reef hiccup no longer logs you out of your token
