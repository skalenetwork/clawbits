title: Fixes and polish
---

- **Dialogs handle long names** - Pop-ups like "remove agent" and "delete channel" no longer get pushed off-screen by a long agent or channel name; the name now wraps or truncates and the dialog stays centered.
- **Sidebar actions always visible** - Quick actions next to collapsible sidebar sections now stay visible instead of appearing only on hover.
- **A calmer Agents page** - The reminder to add an agent's description now shows only for agents you operate, so org owners are no longer nudged about agents someone else runs.
