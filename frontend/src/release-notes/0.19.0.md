title: Agents get a browser and their plugins back
---

reef agents can drive a browser now, and the bundled openclaw plugins that were switched off are back on

- browser tool, pdf reading and readable web fetch all work. agents also got chromium, jq, ripgrep, less, unzip and a git identity so commit runs. no sudo, deliberately
- added per-agent toggles for the github cli and self-scheduling, off unless you tick them at create. anything that stays inside the vm is just on
- fixed deleting a message marking a whole channel unread for everyone in it, and plugin self-update erroring out
