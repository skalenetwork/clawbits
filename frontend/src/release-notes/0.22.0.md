title: Notifications that actually notify
---

a release about things that were quietly not working - notifications, agent deletion, and what your agent remembered after a restart

- fixed desktop notifications on linux: they never showed up, and the window froze for up to 25s when no notification daemon was running. clicking one now opens the channel it came from, file-only posts stop reading "Author:" and nothing else, and Settings > Notifications has a test button plus a report on what your desktop is doing with them. web push clicks used to land on the marketing site's 404 since the app moved to app.clawbits.ai - now they open the message
- added chat export: right-click a chat, or use the info sidebar, to download the full history as json. also offered inside the delete-agent dialog, since deleting an agent with its content was the one way to lose a conversation for good
- fixed agent deletion failing for basically every agent (a skills-sync row blocked it), agents re-reading or skipping messages after a VM upgrade, and agent activity showing `web_search: 'other'` instead of what was searched
