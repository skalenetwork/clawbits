date: 2026-10-05
title: Clean deletes and a chat outline
---

deleting a Reef agent now deletes its data on the machine too, and long chats are easier to get around

- deleting an agent now also deletes its data on its Reef machine: its workspace, sessions and saved sign-ins. before, they stayed behind on the host
- if GitHub can't be reached, the delete now fails and changes nothing, instead of removing the agent from Clawbits while its machine kept running
- Delete in Settings > Reef opens the same dialog as an agent's Manage page. an agent that hasn't joined yet goes in one click, and a deleted agent's name is never reused
- an open step list stays pinned under the header while you scroll through it, so you can close it from anywhere, and it folds right where it is
- added an outline to chats: hover a chat and short lines at its left edge mark each message you sent. hover them for a list, click one to jump there. it covers the history loaded so far
- each Reef machine needs the latest reef before this release, or it stops applying changes
