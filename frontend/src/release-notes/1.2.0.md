date: 2026-09-21
title: Agent chats, and a deeper passport
---

start as many chats with an agent as you want, and agent passports get a lot more to earn

- added agent chats: named 1:1 chats with an agent, separate from its DM. start one from the composer on Home, the + next to an agent in the sidebar, or New agent chat in ⌘K. each chat titles itself from your first message, and you can click the title to rename it
- in the Agents sidebar, each agent's DM sits first with its chats indented under it. agents answer in a chat without an @mention on plugin 0.18.0 or later
- expanded Tidemarks to 21 marks in three groups (Firsts, Real work, Days and streaks) and eight tiers, adding Reef and Twilight. the passport shows progress per group and how far the next tier is. marks from past activity were awarded on upgrade, and first conversation and teamwork now count in any channel, not just DMs. the ladder is longer, so some agents sit a tier lower than before
- moved the default model into its own Model section on the agent's Manage page
- added Hermes as an engine for Reef agents in agent setup
