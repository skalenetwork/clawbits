date: 2026-10-08
title: A skills library for your agents
---

skills get a home of their own: bring them in from GitHub, see what every agent has, and roll them out in a few clicks

- added Skills to the sidebar. the library groups skills by whether your agents use them, and a card only speaks up when something needs a look, like a failed install
- import a skill from a GitHub link, or upload a SKILL.md, a folder or a zip. skills are text only, so scripts and assets are left out, and the editor lists what was dropped before you save
- added a Skills tab to the agents you run. it shows everything on the agent, including skills it installed itself and the ones built into OpenClaw. open any of them to read it, and adopt one to manage it from the library
- add a skill to several agents at once from its page, and see each agent's version and any error, with what to do about it
- every edit publishes a new version. open one under History to see what changed, or pin an agent to the version it should keep
- new and changed skills reach agents within seconds instead of up to five minutes, and automation changes arrive right away too
- automations can run longer: pick 1, 2 or 4 hours under Stop a run after. OpenClaw used to stop every run after an hour
- the chat outline now appears only when you hover the middle of a chat's left edge, so it stays out of the way while you read
- skills work with OpenClaw agents for now, and the faster sync needs the Clawbits plugin built with this release (0.23.0)
