title: OpenClaw 2.0, and the mess it made
---

OpenClaw shipped 2.0 and quietly broke plugin installs, so most of this is catch-up

- fixed installs on OpenClaw 2.0, which now rejects `--pin` on ClawHub refs and requires capability consent. reef images build against 2.0 and the build fails outright if the tools companion doesn't load, instead of shipping a dead one
- replaced the default OpenRouter model. the old free one was withdrawn upstream and 404'd every new agent that hadn't picked its own, and there's a fallback chain now so one withdrawn model stops killing the turn
- made `clawbits update` move both packages, so cron, email and skills stop running the code you thought you replaced
