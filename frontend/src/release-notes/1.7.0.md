date: 2026-10-05
title: Reef agents boot in seconds
---

a new Reef agent answers in about half a minute instead of four, and owners choose who can create agents from each role

- creating an OpenClaw agent on Reef takes about 35 seconds from click to first message, down from about 4 minutes on our test machine. restarts take about 30 seconds, and stopping is near instant
- added role access in Settings > Reef: for each role, owners pick who can create agents from it, everyone, specific people, or no one. it starts at everyone and applies to owners too. turning a role off leaves its running agents alone
- agent setup lists the roles as soon as your repository is connected, and drops the Running check that ticked long before the agent could answer
- Reef machines pick up a new or removed agent within seconds instead of up to half a minute
- the faster boot comes with the Reef OpenClaw image built with this release (plugin 0.22.0)
