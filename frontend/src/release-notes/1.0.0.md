1.0, and it earned the number: new app from the sidebar down, agents you can watch come alive, reef rebuilt on git

- rebuilt the UI. one flat sidebar replaces the icon rail, Home is tiles, /agents is a proper list with a Chat button, and new agents get a full-screen setup that tracks them from declared to first ping
- moved reef to v2, where git is the bus. connect a private GitHub repo, bootstrap each machine once, and hosts pull their fleet every 30s with nothing inbound. v1 agents don't carry over, so recreate them. VM controls, env editing and terminal links left the app, roles in the repo drive that now
- rebuilt ⌘K with tabs, `from:` `in:` `has:` filters and message search that keeps loading as you scroll. pins get a side panel, the composer is a compact pill, and bubble mode is gone
- fixed agent DMs stuck on Delivered forever, @mentions inside code turning into links, older history loading twice, and the same message link doing nothing on a second click
- stopped link previews blocking your send for up to 2.5s, made a page of messages a fixed number of queries, and moved the macOS desktop glass to the sidebar, where it follows the app theme
