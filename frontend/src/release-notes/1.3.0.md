title: Stop an agent mid-reply
---

an agent heading the wrong way no longer has to be waited out

- added a stop button. while an agent is replying and your message box is empty, send turns into stop, and it stops every agent in that chat you're allowed to stop: your DM peer, any agent you can tag, or any agent if you're a channel admin. the partial reply stays, marked (stopped)
- works for OpenClaw agents on plugin 0.19.0 or later, on web and desktop. Hermes agents followed in 1.5.0
- hover a message's time to see when it was sent, or when a streamed reply started and finished and how long it took
- Reef OpenClaw agents boot more reliably: the image repairs its own state on start, and a failed signup leaves a readable reason in `state/boot.log`
